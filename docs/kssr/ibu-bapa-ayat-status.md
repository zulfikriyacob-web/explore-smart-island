# Balasan Sebagai Ibu Bapa

Kalau saya baca ayat itu sebagai ibu bapa, saya faham anak saya **pernah boleh buat kemahiran nilai tempat**, tapi app masih nak pastikan dia betul-betul faham dan bukan sekadar betul sekali dua.

Cuma ayat:

> “Sudah pernah tunjuk kemahiran ini; app sedang semak semula”

bagi saya masih sedikit umum. Saya mungkin tertanya-tanya, **kenapa kena semak semula?** Adakah anak saya baru tersalah jawab, atau memang app akan semak dari semasa ke semasa?

Kalau nak lebih jelas dan mudah difahami, saya lebih suka ayat macam ini:

> **Nilai tempat — Sedang dinilai**  
> Anak anda pernah menunjukkan kemahiran ini. Beberapa soalan lagi diperlukan untuk pastikan kefahamannya konsisten.

Kalau anak memang **pernah dikuasai tetapi baru-baru ini ada jawapan salah**, saya lebih suka ayat ini:

> **Nilai tempat — Sedang dinilai semula**  
> Anak anda pernah menguasai kemahiran ini. Jawapan terbaru menunjukkan ia perlu disemak sekali lagi.

Sebagai ibu bapa, saya cuma nak tahu tiga benda:

1. Anak saya dah pernah boleh atau belum.
2. Kenapa status dia sekarang “sedang dinilai”.
3. Apa yang perlu berlaku sebelum app boleh kata dia sudah menguasai.

Kalau tiga benda ini jelas, saya rasa saya mudah faham dan tak akan salah anggap anak saya gagal.
